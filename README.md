# Monta tu DNS · SMX

Actividad interactiva de introducción al DNS (MP07 Servicios de Red · RA2) para el ciclo SMX.
El alumnado monta paso a paso un servidor DNS (BIND9) para el dominio `smx.lan`: zona directa,
SOA, NS, A, CNAME, MX, zona inversa y PTR, y comprueba las consultas en una escena animada.

- **Actividad:** https://cecacsmx.github.io/monta-tu-dns/
- **Guía de conceptos:** https://cecacsmx.github.io/monta-tu-dns/guia.html
  (árbol de nombres, FQDN, zonas, registros, SOA, resolución, tipos de servidor, BIND9, `dig`, errores típicos y glosario)

Páginas HTML autocontenidas, sin dependencias: se pueden abrir también con doble clic.
